# MEDY ANCES

## Descripción

Sitio web informativo desarrollado como parte de la práctica
N.º 3: Aplicación de estilos y propiedades CSS, correspondiente
a la asignatura Fundamentos de Sistemas Web.

El proyecto presenta información sobre MEDY ANCES, una
microempresa dedicada a la atención espiritual, las prácticas
ancestrales y las terapias alternativas.

El sitio web utiliza HTML5 para su estructura y CSS3 externo
para su presentación visual.

## Tecnologías utilizadas

- HTML5.
- CSS3.
- Git.
- GitHub.
- Visual Studio Code.
- PowerShell.

## Funcionalidades

### Funcionalidad 1: Inicio

- Encabezado y logotipo.
- Menú de navegación interna.
- Presentación de MEDY ANCES.
- Misión, visión y valores.
- Enlaces externos.
- Estilos CSS personalizados.

### Funcionalidad 2: Servicios

- Presentación de servicios tradicionales.
- Galería de seis imágenes.
- Imágenes que funcionan como enlaces.
- Tabla informativa de servicios.
- Formulario de contacto demostrativo.
- Botones de envío y limpieza.

### Funcionalidad 3: Reto

- Sección de bienestar y cuidado personal.
- Recomendaciones de bienestar.
- Dos imágenes adicionales.
- Enlace externo a la Organización Mundial de la Salud.
- Efectos visuales mediante pseudoclases CSS.

## Selectores CSS aplicados

- Selector universal.

- :hover

- :focus

- :last-child

## Propiedades CSS aplicadas

- Colores en formatos HEX, RGB y HSL.
- Fuentes y propiedades de texto.
- Fondos de colores e imágenes.
- Bordes y márgenes.
- Padding.
- Altura y anchura.

- Opacidad.

## Control de versiones

El desarrollo del proyecto se organizó mediante seis ramas:

- main
- desarrollo
- despliegue
- funcionalidad-inicio
- funcionalidad-servicios
- funcionalidad-reto

Las funcionalidades se integraron mediante Pull Requests
hacia la rama desarrollo.

## Ejecución del proyecto

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir el archivo index.html en un navegador web.
4. Navegar por las diferentes secciones del sitio.
